# GitHub Repository Finder

A responsive frontend application that searches GitHub users and displays their public repositories using the GitHub REST API.

## Features

- Search by GitHub username
- Sort repositories by recent updates
- Display descriptions, languages, stars, and update dates
- Loading, empty, not-found, and API-limit states
- Safe external repository links
- Responsive and accessible interface

## Built With

- Semantic HTML5
- Modern CSS
- Vanilla JavaScript
- Fetch API
- Async/await
- GitHub REST API
